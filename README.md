# SRThub

SRThub is a lightweight, browser-based toolkit for subtitle creators, editors, and content researchers.

It helps you generate SRT files, create timestamped YouTube links, and transliterate text — all without uploads, logins, or servers.

Everything runs locally in your browser.

---

## 🚀 Features

### 🎬 SRT Generator
- Convert plain text or quoted multi-line dialogue into valid `.srt` files
- Adjustable duration per subtitle
- Clean formatting
- No external tools required

---

### ⏱️ Timestamper
- Upload an existing `.srt` file
- Generate:
  - Timestamped YouTube links
  - CSV exports
  - YouTube chapter text
- Supports time offsets (useful when subtitles are early or late)

---

### 🔤 Transliteration Tool
- English → Hindi (phonetic)
- Hindi → English (offline, safe)
- Pure transliteration (not translation)
- Paste-safe output (no hidden or broken Unicode characters)
- Ideal for names, subtitles, captions, and titles

---

## 🛠️ How It Works

- 100% frontend only
- No backend
- No database
- No tracking or analytics

SRThub runs entirely in your browser.

---

## 📦 Tech Stack

- HTML5
- CSS (dark, minimal UI)
- Vanilla JavaScript (no frameworks)

---

## 🔒 Privacy

SRThub does NOT:
- Upload your files
- Store your data
- Track your usage

Your content never leaves your machine.

---

## 🎯 Why SRThub Exists

Most subtitle tools are:
- Bloated
- Paid
- Online-only
- Overkill for simple tasks

SRThub was built to be:
- Fast
- Simple
- Offline-friendly
- Creator-focused

---

## ⚠️ Known Limitations

- Hindi → English transliteration uses a lightweight mapping (not a full linguistic engine)
- English → Hindi transliteration may require internet connectivity

These are design choices, not bugs.
